# Costa Axiom Recovery Library v1.7.0

This release provides three zero-command installer images:

- **256 GB:** essential and practical library, about 196 GiB installed;
- **512 GB:** adds Wiktionary, Wikiversity, and Survivor Library, about 412 GiB;
- **1 TB:** complete collection with Khan Academy and Project Gutenberg, about
  786 GiB.

All images support Raspberry Pi 3 Model B/B+, Pi 4 Model B, and Pi 5 Model B.
They include the Costa mobile portal, Axiom hotspot, SSH password access,
wired-internet sharing, 54 practical manuals, illustrated Wikipedia, and
offline North America/Puerto Rico maps.

## Installation

Flash the `.img.xz` directly with Raspberry Pi Imager using **Use custom**. Do
not apply Imager OS customisation. Connect wired Ethernet and stable power for
the first boot. Downloads resume automatically after interruption.

Read the [plain-English installation guide](https://github.com/Joe-CST/axiom-recovery-library/blob/main/docs/INSTALL.md)
before flashing.

## Verification

Each compressed archive was fully decompressed and compared to its verified raw
image SHA-256 value. Matching `.sha256` files are included with this release.

## Public defaults

Default credentials are included in the README and release credential files.
Change both passwords after first setup because this is a public image.
